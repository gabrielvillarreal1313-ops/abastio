# Abastio

Capa de inteligencia operativa sobre ERPs mexicanos para mayoristas y distribuidores.

## Stack

Next.js 14 + TypeScript + Tailwind + Supabase + Vercel + Recharts + sonner + IBM Plex Sans.

## Desarrollo

```bash
npm install
npm run dev
```

Ver `CLAUDE.md` para contexto completo del proyecto.
